## V2 explicit binary32 bit predicate
V1 floating comparison draft remains preserved and unexecuted. V2 loads FP32 without arithmetic then documented ct.bitcast to uint32. For constant0, `(bits & 0x7fffffff)==0` accepts exactly +0/-0; for constant1, `bits==0x3f800000` accepts exactly +1. All subnormal/minnormal/NaN encodings/Inf/adjacent-to1 reject unless mathematically equal. This is exact IEEE binary32 logic, not an epsilon or relaxed criterion. It removes floating comparison from candidate predicate but still requires actual GPU evidence of bit-preserving load/bitcast/readonly semantics. No FTZ behavior of native or compiler is assumed.

Mandatory SYNTHETIC-CASES includes signed zero, signed minimum subnormal, signed maximum subnormal, signed minimum normal, positive/negative quiet+signaling NaN payloads, ±Inf, +1 adjacent representables and finite extrema. GPU qualification must materialize raw integer words and view as FP32 without payload-changing numeric conversion. Compare same-input native public `(x==constant).all()` twice against candidate twice, whole backing raw unchanged. Prior finite tests cannot substitute for this EQ proof. CPU Python unpack equivalence is only reference reasoning, not native Torch/GPU validation.

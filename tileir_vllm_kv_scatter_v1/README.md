M32/1696, H4,D256; actual positive unique slots checked on CPU. Input row stride/offset and cache blocksize/capacity derive from tensors, not old allocation. Inference only; no allocation of output/cache, no gradient support. Existing public Triton alternative gives semantic reference, not evidence that native CUDA dispatch used Triton.

What this project is investigating

Public kernel implementations + TileIR-generated compute
                          │
                          ▼
        Native engine: prepare → prefill → decode → cleanup
                          │
                  correctness gate
                          │
                          ▼
        matched warm comparison against native vLLM
                          │
                          ▼
    isolate runtime difference → patch → regression → A/B

The aim is to approach vLLM-like performance with a TileIR compute path before pursuing LLVM/TileIR pass optimizations. Comparing implementations also teaches us how runtime scheduling, memory lifetimes, synchronization, and diagnostics affect end-to-end latency. It does not imply that every observed improvement reveals a specific vLLM optimization.

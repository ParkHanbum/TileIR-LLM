## Reference versus replacement and active identity
Reference phase remains entirely native and runs before bridge installation. This lean bridge has no native observation/oracle phase and must not be labeled same-input raw proof. Replacement uses previously qualified APIs and requires a new end-to-end/census proof. Before start and finish, both active class attributes must equal the exact installed wrappers and owned GDN body globals must point at the exact guarded jointly transformed conv. Existing metadata5 wrappers are deliberately rejected: next global version must replace metadata5 binding construction with this bridge rather than stacking it afterward.

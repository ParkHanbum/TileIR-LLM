# Public sampling guard primitives: CPU draft only
Scope: independent public TileIR IEEE classification and exact selected-column gather. No CUDA import/compile/GPU performed by CPU tests. Source examples: pinned public tileir_vllm_greedy_sample_v1/api.py, tileir_vllm_selected_ranks_v1/api.py, tileir_vllm_selected_logprobs_v2/api.py; public cuda.tile gather/scatter/reduction and existing checked local templates. No proprietary SASS used.

API classification supports contiguous FP32/BF16 matrices rows<=32,cols<=248320 with typed offset-preserving bit aliases; NaN detection includes every quiet/signaling payload, positive infinity is distinct from negative infinity, rows_have_finite requires at least one finite value in each row. Empty matrices follow all/any semantics. Status read synchronizes at the original host predicate boundary. No fusion across ordered assertions: caller must call has_nan, then has_posinf, then rows_have_finite with original short-circuit. Metadata guards reject unsupported dtype/layout, neg/conj, out-of-backing. Model support is not broadened by this primitive.

Chosen gather preserves raw BF16/FP32 words and returns fresh [rows,1], with IDs checked by the independently developed i64 range API before any dependent read. First version deliberately repeats bounds already checked by original caller; no unsafe unchecked public entry and no forged validation token. Input aliases remain read-only, output is independent. GPU qualification of the range dependency must precede acceptance.

Owned adapter not yet implemented. Existing finite callback in chosen-rank path and scores must remain unchanged; do not overwrite the fresh copied globals of FiniteSites. Caller descriptor/error order remains at original site. Greedy temperature selected-zero is deferred until actual temperature descriptor is observed; do not assume shape/dtype from count evidence.

Next bounded isolated proof: both FP32/BF16, raw words for ±zero,±subnormal,±maxfinite,±infinity,quiet/signaling NaNs and payload signs; one bad element first/middle/last, all-negative-infinity row vs one finite entry; tail1023/1024/1025, offset views, row32 and actual vocabulary248320; checked gather duplicates/first/last/invalid IDs and full-word payload preservation. Native twice vs candidate twice, CPU bit reference independently, entire backing readonly, default/non-default stream. First failure stops. No runtime binding/100%/performance claim before actual GPU and model proof.

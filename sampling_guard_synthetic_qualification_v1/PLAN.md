# Bounded sampling guard qualification CPU draft
Classification cases118: both FP32/BF16, 13 raw class words, each of3 ordered primitives, offset/padding, tails1023/1024/1025, actual matrix32x248320, empty rows/columns, mixed negative-infinity rows. Two gather cases preserve full raw payload words and repeated/edge IDs. Each case runs native twice and candidate twice, comparing an independent CPU bit expectation and entire backing bytes, plus current stream and fresh gather output. Numerical model kernels are not called.
The original caller must invoke individual primitives in original short-circuit order; this isolated suite does not prove an owned model adapter or that order in runtime. Range dependency i64 GPU validation is pending. Temp selected-zero API is not in this first scope. The existing EQ isolated parent lifecycle is reused: common nonblocking flock, fresh exact-GUI admission,585s worker/600s parent, first failure stops, same child is not reused after failure. Source pins and independent review are required before coordinator-only GPU execution. Range32 actual result/launch/recovery is a pinned prerequisite, not a model48 proof. Classification and gather use the current default stream; non-default stream correctness is not claimed by this suite.

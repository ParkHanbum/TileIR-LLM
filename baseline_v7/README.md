# Original v7 verified baseline

This immutable Git baseline fixes original whole_lean_extensions_runtime_v7 and its three-process official-logger/profile evidence. Later G/H/O/M and scratch candidates are excluded. The source archive conservatively includes pinned historical support/tests, not a claim every archived file is active.

SOURCE-ALLOWLIST.json binds original source bytes. BASELINE.json gives canonical entry points and proof hashes. EXTERNAL-EVIDENCE.json binds excluded evidence/runtime/data by path, size and hash without adding payloads. Historical source is unchanged. Models, caches, tensor banks, compiled artifacts, traces, raw address logs and secrets are not committed. Preserve bundled public-source license notices; no additional license is granted here.

The three fixed eager runs had 13,300 own-source compute kernels each, native cuBLAS GemmEx 2,448 positive control / lean zero, and 512 IDs plus 2,560 public values exact. CPU/transfers, experimental Lt logger coverage, and lack of direct loaded-module SHA observation remain explicit limits. This is not all-input API coverage or performance equivalence.

The baseline tag must never move. Executable modular regression tooling belongs in a later commit; outputs/caches stay outside tracked source. Historical manifests require listed external evidence at their original local paths. This is not portable dependency installation tooling.

## Qualifier interface
After engine initialization and native endpoint baseline, instantiate Qualifier(torch, save_callback); set q.binding=Binding(gdn_module,q.call,lambda:q.failed or q.transport.failed,q.mark_failed); install. First run private synthetic(torch), then q.start('shadow') and actual request, require q.finish and frozen512/public2560. Only then q.start('replace') and current-input request; require q.finish and same frozen endpoints. Each phase exactly1 target, unexpected duplicate rejected before work. Close restores binding before synchronizing/releasing pending transport. A failure in any stage aborts the request and requires normal engine cleanup; no automatic retry.

This folder supplies API, owned binding, CPU-tested transport and a GPU qualifier interface, not a model launcher.

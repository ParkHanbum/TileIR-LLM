# Sampler integer three-expression CPU draft
Independent APIs, not installed or GPU-qualified. Source metadata from integer_boundary_ports_design_v1: positions int64[N],input_ids int32[N],idxint64[32], N1696prefill/32decode; each16calls; new_ones int32[32]16calls. Recorded metadata excludes index values/view flags and output ownership. No observed nonnegative/unique-index assumption. Gather supports full signed range[-N,N), maps negative indices toN+i, duplicates and order preserved. Input/index may alias, because both are readonly; fresh output disjoint. OOB rejected on host before candidate allocation/launch, not an assertion of matching native CUDA device-error behavior. Narrow descriptor/ordinary-view flags explicitly fail closed. ones inherits dtype/device but never reads source values; no new sourceflag restriction needed. NaN/Inf not relevant to integer values.

Current source adds indices.cpu().tolist() validation; this host copy/sync is retained, so not100% GPU/native-free. Future observed-contract validation may use separate primitive, not delete guard. Native2/Tile2 qualifier must compare fullowners, return layout/fresh/prior outputs, index negatives/duplicates/OOB boundaries, signed min/max payloads; synthetic fixtures distinct from actual captures.

Owned Sampler.__call__ copy changes exactly three expressions and no ordering. It must install FIRST before Counts/Greedy/SamplerFour and later four-helper wrapper chain so those adapters capture it as original and their pending/census contexts remain active. Crucial: copied __globals__ cannot freeze original helper function pointers. Bind explicit live delegation proxies for get_num_nans,compute_topk_scores,get_num_sampled_and_rejected, resolving the current original module attribute at call time; do not overwrite that module or create recursion. Existing self.sample/self.apply_sampling_params stay dynamically bound. Later finite and greedy helper replacements then remain visible. If the actual final composition has a different owner/copy boundary, HOLD rather than overwrite it. Reverse close all outer adapters first, this copied __call__ last. Installed-flow mock must assert 16gatherpositions+16gatherIDs+16ones and all existinghelper counters before GPU. No such runtime installer exists yet; this file is an explicit integration plan, not completion proof.

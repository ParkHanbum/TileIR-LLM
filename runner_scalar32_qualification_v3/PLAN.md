# Scalar32 v3: current-input oracle, not cross-request state identity

Public scalar kernel unchanged; API only changes explicit package namespace v2→v3. Binding preserves exact original method source/dedent AST, lexical __class__/super ordering and dynamic owned caller. Original v2 failure is retained and linked in PREVIOUS-FAILURE.json. Its exact mismatch field/previous candidate count is unknown: no such old ledger existed. No zero-candidate claim.

Same original eager B32/P53/G16 T/T runtime, native endpoint baseline, private synthetic32, then shadow32 and conditional replacement32. Whole128B checks remain exact. Replacement uses its CURRENT typed backing preimage and integer CPU fill oracle, corroborated by native fill on an independent typed clone. The original backing is checked unchanged by this private oracle; only candidate writes original. No cross-request slot-order or preimage identity assumption remains. Unique slots0..31 and exactly32 calls/phase still required; inactive124B preservation is part of entire128B equality. Shadow32 remains prerequisite, but does not claim exhaustive input-domain proof.

Every target records current preimage+expected bytes, native original/private intent+return, candidate intent+return and synchronized fullbacking verification. JSONL callback flushes and fsyncs each event before proceeding. Candidate return denotes Python API return, not GPU success; verified follows snapshot synchronization. Failure records include exact phase/index/stage history. Source guard failures have entry_failure records; persisted failure means HOLD. Parent hashes ledger and compares it to RESULT snapshot when available. Crash/OOM may leave only a durable prefix; never infer an unrecorded return. Record-write failure stops execution, though a failed filesystem cannot guarantee subsequent failure record durability.

Worker900s / parent930s, fresh destination cache gate before admission, common lock, actual process exit and post-recovery unchanged. Numerical source, runtime settings, cache and old failure artifacts were not modified.

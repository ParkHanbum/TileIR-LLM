2026-11-16 / synthetic standalone logits qualification

Keep stored logits in BF16.
Remove one materialization, keep the verdict.

On a synthetic stored-BF16 [32,248320] bank on RTX 4080, the median paired reduction in the sum of separate kernel event intervals was 33.3354473762%, favorable in all eight rounds. Legacy and BF16 arm event-sum medians were 0.1325920019 ms and 0.08694399985 ms. Their ratio is not the paired statistic.

This is not model latency, a contiguous logits-pipeline interval, GPU busy time or a cache-neutral result. The mandatory host finite verdict, uploads, allocation and postchecks are excluded. No native model integration or vLLM measurement is supplied by this experiment.

The two paths

legacy stored BF16
  → cast whole bank to FP32 → finite FP32
  → HOST: check all 7,760 status words
  → FP32 block maxima → shared finish → 32 IDs

new stored BF16
  → finite BF16
  → HOST: check all 7,760 status words
  → BF16 gather + FP32 local block math
  → same finish → 32 IDs

The candidate avoids the full FP32 materialization in this isolated path; it does not replace local FP32 arithmetic with approximate BF16 arithmetic. Both paths retain the full finite-status decision before any greedy block or finish call. Removing a materialization in a future runtime also changes allocation, cleanup and failure opportunities, which this standalone harness does not qualify.

Fixture and numerical contract

The input is contiguous little-endian stored BF16, shape [32,248320], strides [248320,1], 15,892,480 bytes. The FP32 legacy bank is 31,784,960 bytes. Blocks contain 1,024 elements: 243 greedy blocks per row, with 512 valid and 512 masked elements in the final block. Compact V and I have shape [32,243]; final IDs contain 32 int64 values. The finite-status map contains exactly 7,760 int32 words.

Two distinct valid fixtures were qualified: an adversarial bank and a nominal deterministic bank, with nominal repeated. Adversarial row 0 covers all 65,280 finite BF16 encodings. Other rows cover alternating signed zero, lowest-index ties, all-negative maxima, cross-block ties and final-half-tile winners. Three invalid fixtures inject signed signaling/quiet NaNs, +Inf and −Inf at fixed global, row, chunk and tail boundaries. Each invalid fixture is checked in both arms, for six expected negative paths.

Valid paths require exact status arrays, CPU-oracle compact values/indices and exact final 32 IDs. Across arms compact V raw bits, including signed zero, and I must match strictly. The numeric CPU V oracle alone permits either zero sign; this never relaxes the cross-arm raw-bit check. Invalid inputs must yield the exact expected status map, no greedy calls, and unchanged poisoned compact/ID outputs. An arbitrary CUDA error is not an accepted negative result. Read-only A, bound extents and all guards are checked; sentinel success is not proof of absent out-of-bounds reads.

Only the nominal synthetic bank is timed. Every measured kernel has its own stream-event interval after upload/poison/live preparation and before postchecks. The full host finite verdict occurs between finite and greedy, outside these intervals. Summing intervals does not restore the excluded host work or make a contiguous pipeline measurement. Balanced arm positions do not guarantee cache neutrality or eliminate carryover. GUI holders remained; sampled utilization does not establish idle conditions.

The child, launcher and independent recovery returned actual exit 0. Independent saved-data audit passed (seal 6b42b9e7). Only first qualification compact outputs/status maps were independently retained raw: 22 files totaling 560,256 bytes. Full input/cast and later repeated, warm and timed validations ran in child RAM with digests; not all raw GPU outputs are archived or provided by this article.

Reproduce the fixtures and statistic

Download the original CPU-only fixture generator and the sanitized specification and expected content hashes. The recorded generator used NumPy 2.4.6. Save the generator under its exact filename in a fresh writable directory, then run:

python3 make_fixtures.py

It creates a new fixtures/ directory and FIXTURE.json without overwriting existing files. It runs no GPU workload. The manifest includes local output paths, so compare fixture bytes/hashes rather than expecting a relocated manifest to have the original hash. Generator SHA256: ed9802cf7f59fdcf5dba729d993794dca0ce51ec394df62c6ecd18abf367fc3c. GPU binaries and the complete benchmark harness are not distributed here; this is a reproducible fixture/statistic package and execution specification, not a self-contained GPU benchmark.

Download all 56 chronological event samples (CSV) or the public projection (JSON). For each round, sum the legacy intervals and the BF16 intervals separately. Compute 1 − BF16_sum / legacy_sum, then take the median of the eight reductions. All eight are positive. Do not calculate the headline from the ratio of arm medians.

What follows, and what does not

The result supports further integration qualification of this particular standalone path. It does not automatically promote a default, predict token generation speed or update the historical 8.43× matched native/vLLM checkpoint. Synthetic stored logits are not real model logits, and standalone event sums are not inference request time.

2026-11-15 / kernel pilot K05 · Gated DeltaNet decode descriptors

Much smaller generated code.
A modest measured kernel gain.

A same-source descriptor specialization reduced the generated GDN decode kernel's static register and instruction counts substantially. Its measured two-step operation envelopes improved by only about 2.6–3.3% against the deployed export in this synthetic pilot. Static simplification is not a proportional speedup guarantee.

This is standalone kernel qualification evidence, not a model request or vLLM comparison. No candidate promotion or broader performance claim follows from this pilot.

Where the change lives

The kernel already implements a fused packed recurrence. This experiment does not introduce that fusion, rewrite the algorithm or change its mathematics. It specializes the descriptor facts used when exporting the same recurrence source.

deployed: existing fused packed recurrence export
C64:      same-source generic control for the actual binding
S64:      same computation + exact shape/stride/alignment facts

Unchanged: math, data layout, 43-parameter ABI
Changed:   descriptor facts for the live compact binding

C64 matches the deployed kernel's full SASS dump, including instruction encodings, while the ELF files differ. That is stronger evidence than matching an instruction count, but it is not byte identity of the entire binary artifact.

Correctness before timing

A separate frozen six-call qualification established raw equality of state (S) and output (O), comparing 69,206,016 and 262,144 bytes respectively per produced result. Each arm used its own state; the spare slot 0 remained preserved. The nonpositive-slot branch (<= 0) was not tested.

The focused timing experiment comprised 54 calls: 6 qualification, 12 warm and 36 timed. All required checks, actual exits and independent recovery passed. These tests cover the exercised synthetic case, not every state layout, branch or model workload.

The event values measure stream elapsed time around checked submission, not GPU-busy time alone. Step 2 occurs after full validation of step 1, so this is not a contiguous two-step recurrent execution timing. After the stop wait, full S/O D2H and raw, finite, input and guard checks precede step 2. This intervening state readback affects step-2 residency; no measured DRAM traffic or bandwidth is reported. Shared memory remains 3,328 bytes in both exports. Validation and readback can alter the execution/cache context between steps; the single bank is not a broad cache-regime study.

Developer lesson and next discriminating test

Exact binding facts can materially change generated code without a correspondingly large wall-clock improvement. For this kernel, preserve the small measured benefit as a small benefit. Do not convert static reductions into an inferred model-speed gain.

A same-source one-factor ablation can separate shape, stride and alignment contributions. Broader independent state/binding cases, the untested nonpositive-slot branch and a contiguous execution contract need qualification before extrapolation. Any model integration then needs its own correctness gates and request-level timing; no such result is claimed here.

# Public slot mapping CP1 companion, CPU-ready / GPU untested

Source path: GPUModelRunner.prepare_attn -> BlockTables.compute_slot_mappings -> _compute_slot_mappings_kernel. Existing optimized inventory K049 has96 events across6 requests. Kernel-name evidence is not pointer/dtype/argument capture and does not establish eager/optimized equality. Actual first-prefill/decode capture is prepared separately in slot_mapping_runtime_capture_v1; no new GPU execution has occurred.

`compute_slot_mappings(tables, indices, starts, positions, sizes, enabled, out, padded, cp_size=1)` accepts nonempty tuple int32 contiguous tables, int64 indices/positions, int32 query starts/block sizes, bool enabled, int64 contiguous [group,capacity] out. It mutates out and returns out[:,:padded], preserving backing lifetime and row stride (prefix may be noncontiguous). No internal allocation/copy/fallback, current device stream, one TileIR launch per group. All metadata/entire backing overlap checks precede launches. CUDA-visible mapped storage is not presumed device-resident. Actual operand placement/widths/block sizes remain unobserved until capture.

CP1 semantics: for request token position p, enabled real request gives table[req,p//blocksize]*blocksize+p%blocksize. Negative reqidx gives -1 without table access. Disabled group gives -1; public native nevertheless reads column0 for real requests. All slots from starts[last] through ENTIRE output capacity end become -1, not merely through returned padded prefix. Prefix starts must begin0, monotonic, last<=padded/capacity and<=positions length. Positive sizes/nonnegative positions, valid row/block indices and nonnegative block product<=INT32_MAX are explicit narrow value preconditions; CPU snapshot helper checks them. Native int32 block product precedes int64 position addition; no unsupported overflow equivalence claim. Runtime does not host-read GPU values for validation.

Unsupported: CP_SIZE>1 sharding/interleave/rank semantics, empty groups, noncontiguous operands, int32 request indices or positions, negative positions, overflow domain, out/input overlapping backing storage, custom pointer-array ABI, optimized graph binding. These are rejected metadata or documented value preconditions, not silently mapped to another algorithm. Source has broader capabilities than this initial facade.

CPU6 tests cover positive mapping, disabled group, dummy request, zero token batch, entire capacity padding beyond returned prefix, strided alias return, value bounds/overflow, metadata CP/dtype and distinct-storage overlap. No GPU or compiler initialization, no exact/runtime coverage claim. License/source snapshot retained under public_sources; installed source hash not executable identity proof.
